# 증강 3선택 시스템 설계 문서

## 개요

웨이브 클리어 시 3개의 증강(버프) 중 하나를 선택하는 로그라이크 스타일 강화 시스템.
기존 코드 수정을 최소화하고, 프리팹 하나만 씬에 배치하면 동작하도록 설계.

---

## 시스템 구조

```
AugmentManager (싱글톤)
├── EnemySpawner.OnWaveClear 이벤트 구독
├── 웨이브 클리어 감지 → Time.timeScale = 0 (게임 일시정지)
├── 풀에서 랜덤 3개 선택 → AugmentUI에 전달
├── 플레이어 선택 → PlayerStatModifier에 적용
└── Time.timeScale = 1 (게임 재개)

PlayerStatModifier (싱글톤, 플레이어에 부착)
├── 스탯 배율 필드들 (기본값 1.0)
└── 기존 시스템들이 이 배율을 참조하여 스탯 반영

AugmentUI → AugmentCard × 3
├── DOTween 애니메이션 (SetUpdate(true)로 timeScale 무관 동작)
└── 카드 클릭 → AugmentManager.OnAugmentSelected 콜백
```

## 생성된 파일 (5개)

| 파일 | 경로 | 역할 |
|------|------|------|
| `PlayerStatModifier.cs` | `Augmentation/` | 스탯 배율 싱글톤. 기존 시스템이 `PlayerStatModifier.Instance?.XXXMult ?? 1f`로 참조 |
| `AugmentData.cs` | `Augmentation/` | ScriptableObject. 에디터에서 `Create → Game → AugmentData`로 생성 |
| `AugmentManager.cs` | `Augmentation/` | 핵심 매니저. 웨이브 클리어 감지 → 3선택 UI → 스탯 적용 |
| `AugmentUI.cs` | `Augmentation/` | UI 패널 컨트롤러. Show/Hide + DOTween 애니메이션 |
| `AugmentCard.cs` | `Augmentation/` | 개별 카드. 이름/설명/아이콘/등급색상 표시 + 버튼 클릭 |

## 기존 파일 수정 내역 (4개)

### Jaein_PlayerController.cs (2곳)

**1) Move() - 이동속도 배율 적용**
```csharp
// 변경 전
float speed = _weaponSystem.IsCharging ? _moveSpeed * 0.5f : _moveSpeed;

// 변경 후
float statMult = PlayerStatModifier.Instance != null ? PlayerStatModifier.Instance.MoveSpeedMult : 1f;
float speed = (_weaponSystem.IsCharging ? _moveSpeed * 0.5f : _moveSpeed) * statMult;
```

**2) HandleDash() - 대시 쿨다운 배율 적용**
```csharp
// 변경 전
if (... && Time.time >= _lastDashTime + _dashCooldown && ...)

// 변경 후
float dashCD = _dashCooldown * (PlayerStatModifier.Instance != null ? PlayerStatModifier.Instance.DashCooldownMult : 1f);
if (... && Time.time >= _lastDashTime + dashCD && ...)
```

### Jaein_BatWeaponManager.cs (3곳)

**1) HandleAttackInput() - 차지 속도 배율**
```csharp
// 변경 전
_currentChargeTimer += Time.deltaTime;

// 변경 후
float chargeMult = PlayerStatModifier.Instance != null ? PlayerStatModifier.Instance.ChargeSpeedMult : 1f;
_currentChargeTimer += Time.deltaTime * chargeMult;
```

**2) ExecuteAttack() - 배트 데미지 + 넉백 배율**
```csharp
// 변경 전
int dynamicDamageAmount = Mathf.RoundToInt(Mathf.Lerp(...));
float dynamicKnockbackForce = Mathf.Lerp(...);

// 변경 후
float batDmgMult = PlayerStatModifier.Instance != null ? PlayerStatModifier.Instance.BatDamageMult : 1f;
float kbMult = PlayerStatModifier.Instance != null ? PlayerStatModifier.Instance.KnockbackMult : 1f;
int dynamicDamageAmount = Mathf.RoundToInt(Mathf.Lerp(...) * batDmgMult);
float dynamicKnockbackForce = Mathf.Lerp(...) * kbMult;
```

**3) ExecuteAttack() - 공격 범위 배율**
```csharp
// 변경 전
float hitRadius = Vector2.Distance(pivot.position, _endpointTransform.position);

// 변경 후
float rangeMult = PlayerStatModifier.Instance != null ? PlayerStatModifier.Instance.AttackRangeMult : 1f;
float hitRadius = Vector2.Distance(pivot.position, _endpointTransform.position) * rangeMult;
```

### Jaein_OrbitalWeapon.cs (2곳)

**1) Launch() - 공 발사 속도 배율**
```csharp
// 변경 전
_velocity = launchDir * (_launchSpeed * powerMultiplier + Random.Range(...));

// 변경 후
float ballSpeedMult = PlayerStatModifier.Instance != null ? PlayerStatModifier.Instance.BallSpeedMult : 1f;
_velocity = launchDir * ((_launchSpeed * powerMultiplier + Random.Range(...)) * ballSpeedMult);
```

**2) CalculateDamage() - 공 데미지 배율**
```csharp
// 변경 전
float rawDamage = Mathf.Lerp(_baseDamage, _maxChargeDamage, chargePercent);

// 변경 후
float ballDmgMult = PlayerStatModifier.Instance != null ? PlayerStatModifier.Instance.BallDamageMult : 1f;
float rawDamage = Mathf.Lerp(_baseDamage, _maxChargeDamage, chargePercent) * ballDmgMult;
```

### Jaein_PlayerBase.cs (2곳)

**1) InvincibleRoutine() - 무적 시간 배율**
```csharp
// 변경 전
while (elapsed < _invincibleDuration)    // 피격 시
yield return new WaitForSeconds(_invincibleDuration);  // 비피격 시

// 변경 후
float duration = _invincibleDuration * (PlayerStatModifier.Instance != null ? PlayerStatModifier.Instance.InvincibilityMult : 1f);
while (elapsed < duration)              // 피격 시
yield return new WaitForSeconds(duration);  // 비피격 시
```

**2) 새 메서드 추가 - IncreaseMaxHp()**
```csharp
public void IncreaseMaxHp(int amount)
{
    _maxHp += amount;
    _hp = Mathf.Min(_hp + amount, _maxHp);
    OnDamaged?.Invoke(_hp);
}
```

## 스탯 배율 매핑표

| AugmentStatType | PlayerStatModifier 필드 | 적용 위치 | 효과 |
|-----------------|------------------------|-----------|------|
| MoveSpeed | MoveSpeedMult | PlayerController.Move() | 이동속도 곱하기 |
| BatDamage | BatDamageMult | BatWeaponManager.ExecuteAttack() | 배트 데미지 곱하기 |
| BallDamage | BallDamageMult | OrbitalWeapon.CalculateDamage() | 공 데미지 곱하기 |
| Knockback | KnockbackMult | BatWeaponManager.ExecuteAttack() | 넉백 힘 곱하기 |
| ChargeSpeed | ChargeSpeedMult | BatWeaponManager.HandleAttackInput() | 차지 타이머 가속 |
| BallSpeed | BallSpeedMult | OrbitalWeapon.Launch() | 공 발사속도 곱하기 |
| AttackRange | AttackRangeMult | BatWeaponManager.ExecuteAttack() | 히트 반경 곱하기 |
| DashCooldown | DashCooldownMult | PlayerController.HandleDash() | 쿨다운 곱하기 (음수값으로 감소) |
| Invincibility | InvincibilityMult | PlayerBase.InvincibleRoutine() | 무적 시간 곱하기 |
| MaxHp | (직접 호출) | PlayerBase.IncreaseMaxHp() | 정수만큼 최대HP 증가 |

```

    │
    └── Overlay (Image)

            │
            ├── TitleText (TextMeshPro)
            │   Text: "증강 선택"

            │   Anchor: Top Center, Y Offset = 60
            │
            └── CardContainer (HorizontalLayoutGroup)
                │  Spacing: 30, Child Alignment: Middle Center
                │  Anchor: Stretch
```

### Step 3: 연결

1. `AugmentManager` Inspector:
   - `_augmentPool`: 10개의 AugmentData SO 전부 할당
   - `_augmentUI`: AugmentCanvas의 AugmentUI 컴포넌트 연결
   - `_choiceCount`: 3
   - `_showOnBossWaveOnly`: false (모든 웨이브) 또는 true (보스만)

2. `AugmentUI` Inspector:
   - `_canvasGroup`: 자신의 CanvasGroup
   - `_panel`: Panel RectTransform
   - `_cards`: Card0, Card1, Card2의 AugmentCard 컴포넌트 (Size 3)

3. 각 `AugmentCard` Inspector:
   - `_background`, `_rarityBorder`, `_icon`, `_nameText`, `_descriptionText`, `_button` 연결

4. 전체를 프리팹으로 저장 → 어떤 씬이든 배치하면 동작

## 동작 흐름

```
1. 게임 시작
   └─ AugmentManager.Start()
      ├─ FindObjectOfType<EnemySpawner>() → OnWaveClear 구독
      └─ FindObjectOfType<PlayerController>() → PlayerStatModifier 확보/추가

2. 웨이브 클리어
   └─ EnemySpawner.NextWave() → OnWaveClear 이벤트 발생
      └─ AugmentManager.OnWaveClear()
         ├─ Time.timeScale = 0 (게임 정지)
         ├─ 풀에서 랜덤 3개 선택 (중복 없음)
         └─ AugmentUI.Show(choices, callback)
            └─ 카드 3개 설정 + 페이드 인 + 카드 팝업 애니메이션

3. 플레이어가 카드 클릭
   └─ AugmentCard.Button.onClick
      └─ AugmentUI.OnCardClicked(data)
         ├─ 모든 카드 비활성화 (중복 클릭 방지)
         └─ AugmentManager.OnAugmentSelected(data)
            ├─ ApplyAugment(data)
            │  └─ PlayerStatModifier.XXXMult += data.value
            ├─ AugmentUI.Hide() (페이드 아웃)
            └─ Time.timeScale = 1 (게임 재개)

4. 이후 전투에서 적용
   └─ 기존 시스템들이 PlayerStatModifier.Instance?.XXXMult를 참조
      예: Move()에서 speed * MoveSpeedMult → 증강된 이동속도
```

## 확장 포인트

- **새 증강 추가**: AugmentData SO만 만들어서 풀에 추가하면 끝
- **새 스탯 추가**: PlayerStatModifier에 필드 추가 → AugmentManager.ApplyAugment에 case 추가 → 기존 시스템에 1줄 추가
- **등급별 확률**: AugmentManager.GetRandomAugments()에 가중치 로직 추가 가능
- **최대 스택 제한**: AppliedAugments 리스트로 같은 증강 중복 횟수 체크 가능
- **증강 UI 커스텀**: AugmentUI/AugmentCard의 SerializeField 수정 또는 서브클래스
